# 调用示例

## 先规划配图位置

```text
用 $jason-illustrations 只做配图规划。从下面的正文选 2 处最值得解释的段落，每处给我一句核心意思、jason 的动作与道具、图上短词和建议插入位置。

[粘贴正文]
```

## 为一个观点生成单图

```text
用 $jason-illustrations 画一张正文插图。读者需要理解：改完一份草稿后，用同一条检查标准再看一次，才能知道改动有没有解决原问题。让 jason 亲自做出这个检查动作。
```

## 按正文生成一组图

```text
用 $jason-illustrations 给下面这篇文章生成 3 张图。三张统一用 jason 的透明眼镜和奶油色短袖，每张讲不同的观点，分别保存为 PNG。交付时标出对应段落。

[粘贴正文]
```

## 只取本张生图 Prompt

```text
用 $jason-illustrations 只写一条可直接使用的 Prompt。主题是「把收到的反馈变成下一次修改」，给我 jason 操作什么物件、物件发生什么变化，以及建议的短标注。
```

## 修改已有图

```text
用 $jason-illustrations 编辑这张已有配图。把右侧纸签上的「下一不」改成「下一步」，沿用原图的手写字和笔画颜色。
```

```text
用 $jason-illustrations 把这张图里的 jason 改成确认过的手绘画法。照《想法压机》的发型、镜框和墨线重画人物，衣装暖色平涂，双手继续握住图中原有的道具。
```
