# 生图与局部改图 Prompt

生成时实际附上手绘第 06 张。若另有编辑底图，在提示开头写清哪张提供内容布局、哪张提供 jason 的画法。括号中的变量应先按本段正文填实。[手绘主参考](../assets/examples/06-idea-press.png)

## 单张生成

```text
生成一张独立的 16:9 横版中文正文配图。主题是「{主题}」，希望读者看懂「{一句话核心意思}」。随附的手绘样图用于校准 jason 的外形、线条和上色。本张只画下面指定的场景和文字。

用带自然起收的细黑墨线画 jason，约两头半身。深棕发束蓬松后梳，露出额头，双颊饱满，眉眼简练，暖棕色眼睛。戴横向细金属圆角方框眼镜，可见的小银耳圈，近景保留右眼下的小痣。选择{衣装与镜片}。肤色、头发、衣服用几块暖色平涂，衣褶用少量折线。避免渐变塑形、镜面发丝、立体渲染和布料织纹。

jason 正在{具体动作}。他的{手指、重心或视线}落在{与道具的接触点}，使{道具或状态的可见变化}发生。构图中{人物、主要道具与留白的位置}。

画面为纯白底，使用同一支细黑笔画道具，内部留白。用{需要的流向箭头或重点批注}辅助理解。图上文字限定为{每个短词及其位置，或无文字}。每次生成一张完整的图。
```

默认衣装可填“奶油色短袖 Polo，红色领角、蓝色胸袋点色，暖卡其卷边裤、白鞋，透明镜片”。要生成多张时，为每张换掉主题、动作、物件和标注。

## 人物显得立体时

```text
图 1 是要修改的底图，图 2 是手绘 jason 的画法参考。把图 1 中每一处 jason 从发梢到鞋底重新画成图 2 的二维人物。保留他原有的位置和{具体动作、手和道具的接触关系}。发束用几根弧线概括，脸和衣服用平面色块，透明镜片露出眼神。去除发丝反光、皮肤渐变、布料织纹和脚下投影。保留底图的道具、文字、箭头与画幅。
```

## 改字或去标题

```text
编辑所附图片。将{位置}的「{原字}」改成「{正确短词}」，匹配附近手写字的笔画和颜色。若请求是删除标题，则连同其下划线用相邻的纯白背景补齐。保留人物动作、道具边线和其他标注，维持原画幅。
```
