# 从正文关系到 jason 的动作

从原文中选一句读者需要看懂的话。圈出其中的动词，再找一个能使动作及其结果同时可见的物件。例如“根据反馈调整下一步”可以画成 jason 收到回执后亲手拨动岔道。新文章先从本段含义找物件与姿势。用户点名要沿用某个案例时，再参考该案例的布局。

| 结构 | 适合的内容 | 怎样让 jason 参与 |
| --- | --- | --- |
| 流程 | 输入、处理、输出有明确顺序 | 他把材料送进一个工位，另一端出现与输入不同的结果。 |
| 系统局部 | 概念涉及许多模块，正文只讲一个环节 | 放大他操作的闸门、滑槽或拉杆，只留下会影响这个动作的相邻部件。 |
| 前后对比 | 规则或条件一变，结果也跟着变 | 在同一物件上换一张纸签、调一个刻度，让读者看见差别。 |
| 角色状态 | 从迟疑到做出选择，或从混乱到有序 | 用同一角色前后的手势、视线和桌上材料表现状态变化。 |
| 概念隐喻 | 一个判断能被一个物理动作讲清 | 为正文选一个低科技物件，让 jason 通过按、拉、称、折或拼接改变它。 |
| 方法分层 | 上下层各自承担不同工作 | 让他抽出、叠起或翻开某一层，露出该层对结果的贡献。 |
| 路线与回路 | 过程有交接、回流或反馈 | 让他在交接处扣上线，去程、回程都画出明确的终点。 |
| 短漫画 | 必须分两三个时刻才能讲清 | 用 2–4 个简短场面连成一张正文图，同一人物的穿搭和道具连续。 |
