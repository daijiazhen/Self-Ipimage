# jason 角色与换装

**第 06 张是人物画法的主参考。** 看发型轮廓、眼镜的宽高、眉眼和脸颊的相对位置，再看两只手如何握住同一根摇柄。将这些识别点带入新场景，姿势随正文变化。[想法压机](../assets/examples/06-idea-press.png)

| 部位 | 落笔时抓什么 |
| --- | --- |
| 身形 | 正面全身约两头半高，双颊饱满，下巴微收。弯腰、蹲姿时用关节和重心表现用力。 |
| 头发 | 深棕色，露额，两侧收拢，顶部蓬松地向上、向后梳。用几束大弧线勾发束，内部平涂。 |
| 五官与配饰 | 深色眉、暖棕眼、细金属圆角方框眼镜。可见的耳朵画小银圈。正面角色右眼下有一颗小痣，即读者看到的左侧。镜框内留出眼神，视线跟着动作。 |
| 衣装 | 奶油色短袖翻领 Polo，领尖一点红，胸袋口一点蓝。下穿暖卡其卷边长裤、棕腰带、白色系带鞋。 |
| 可变项 | 镜片可透明或浅琥珀色，衣服配色可在暖色系内调整。可在 Polo 外加驼色翻领短夹克。普通眼镜、短袖是三张定稿采用的组合。 |

小尺寸优先画清发型、镜框、头身比例和衣领色块。近景再补小痣和耳圈。表情可以微笑、专注、吃力或吃惊，由当下动作决定。同一个 jason 在一图中出现两次时，两处沿用同一套脸型、眼镜和服装。画面里另有读者或同事时，可用空心简笔轮廓区分身份。[两个断点](../assets/examples/01-two-breakpoints.png)
