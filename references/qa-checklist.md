# 验图与返修

验图时先在正文阅读尺寸看一遍，再放大看字和手。对系列图逐张检查。主参考采用第 06 张。[想法压机](../assets/examples/06-idea-press.png)

| 看哪里 | 通过的表现 | 需要调整时 |
| --- | --- | --- |
| 意思与动作 | 能说出 jason 做了什么，以及它说明了正文哪一句 | 换成有结果的动作，让手真正抓、递、推或接住物件。 |
| 角色 | 露额后梳发束、脸型、细镜框和衣装可认，相邻画面的同一角色一致 | 对照手绘参考重画有偏差的人物，对两次出场的角色分别复核。 |
| 笔触 | 人物是墨线和暖色平涂，道具是白面细黑线 | 皮肤、头发或衣服出现三维光泽时，按人物返修模板重画其线稿和色块。 |
| 手与道具 | 手指遮挡、重心、视线和运动方向说得通 | 放大接触处调整。可参考第 05 张握绳与桶把的连接。 |
| 中文 | 指定的字逐字正确，贴近对应物件，箭头指向正确 | 少量错字做局部编辑，多处挤压时先压缩标注再出图。 |
| 画幅与交付 | PNG 可打开、为 16:9 横版，线条和文字完整，文件与段落对应 | 核对像素尺寸。仅差少量边缘像素时，可在四周补白导出，保全画面内容。 |

返修后再看一次改动位置以及周围的手、物件和文字。保留前一版供对照。[信息井](../assets/examples/05-information-well.png) · [返修 Prompt](prompt-template.md)
